# SAIL Speaking Lab

삼성 SAIL 영어 말하기 시험(Level 5, 목표 AH) 대비 개인 학습 앱. 홈 화면에 설치해서 쓰는 웹앱(PWA)입니다.

**앱 주소:** https://joon7777.github.io/sail-speaking-lab/

## 들어 있는 것
- **오늘:** 30일 반복 레슨. 하루 핵심 표현 5개(한국어 어감·톤 표시) + 질문 1개의 모범 답안과 AI 면접관 팔로업. 답안 위에 강세·억양·끊어 읽기 표시, 한국어 어감 보기.
- **표현:** 핵심 표현 150개, 외움 체크.
- **녹음:** 폰 마이크로 바로 녹음 → WAV 저장 또는 ChatGPT로 공유 + 평가 요청문 복사.
- **SAIL:** 시험 형식·난이도·평가 기준·Level 5 전략 정리 (어학원 분석·응시 후기 기반, 공식 자료 아님).

## 폰에 설치
- **Android (Chrome):** 주소를 열고 '설치하기' 버튼, 또는 ⋮ 메뉴 → 앱 설치.
- **iPhone (Safari):** 공유 버튼 → 홈 화면에 추가.

학습 기록은 각 기기 안(브라우저 저장소)에만 저장됩니다.

## 업데이트할 때
`index.html`을 고친 뒤 `sw.js`의 `CACHE` 버전을 올려야 설치된 앱이 새 버전을 받습니다.
